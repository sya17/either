# Security policy

## Supported versions

either is pre-release software (before 0.1.0). No version is supported yet, and nothing is installable. This policy applies from the first release.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability** (private vulnerability reporting).

Include what you found, how to reproduce it, which component and version are affected, and the impact you expect. If you can, suggest a fix.

You will receive an acknowledgement, and we will keep you informed while the report is investigated and fixed. Please allow time for a fix before you disclose the problem publicly.

## Scope

Reports about the code in this repository are in scope: the daemon, the CLI, the shell, the IPC contract, the packaging, and the install and update tooling. Vulnerabilities in upstream projects (Hyprland, Quickshell, Qt, and others) should be reported to those projects.
