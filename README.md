# either

either adalah sistem desktop Arch Linux di atas Hyprland. Shell dibangun dengan Quickshell (Qt 6/QML), daemon `eitherd` dan CLI `either` dengan Rust. Seluruh stack gratis dan open source.

**Status: pra-0.1.0.** Fondasi development siap; belum ada fitur yang bisa dipakai. Rencana rilis 0.1.0 sampai 1.0.0 ada di [ringkasan](docs/overview.md#rencana-rilis).
