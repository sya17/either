## Nama dan logo sebagai merek

Lisensi CC BY-SA 4.0 hanya mengatur hak cipta file, **bukan** hak atas merek. Nama "either" dan logo Orbit adalah tanda identitas proyek. Sampai kebijakan trademark resmi terbit (U30, sebelum 1.0), berlaku aturan sementara berikut:

- Logo boleh dipakai tanpa diubah untuk merujuk ke proyek either, misalnya di artikel, ulasan, tangkapan layar, atau tautan.
- Versi logo yang sudah diubah, serta distribusi turunan atau fork, **tidak boleh** tampil sebagai either resmi dan tidak boleh memakai nama "either" sebagai nama produknya.
- Untuk pemakaian lain, hubungi pemilik proyek.

## Font di dalam aset

Wordmark di `logos/` dan `sub-brands/` memakai **Manrope** (Light 300) yang sudah dikonversi ke outline. File font-nya tidak didistribusikan di folder ini.

- **Manrope:** SIL Open Font License 1.1, © 2018 The Manrope Project Authors (https://github.com/sharanda/manrope). Tidak ada Reserved Font Name.
- Menurut OFL FAQ 1.1 dan 1.13, karya grafis yang dibuat dengan font OFL, termasuk logo dari outline-nya, tidak ikut berlisensi OFL. Atribusi di atas dicantumkan sebagai bentuk penghargaan, bukan kewajiban.
- Jika repo kelak **ikut membundel file font Manrope** (`.ttf`/`.otf`/`.woff2`), `OFL.txt` wajib disertakan bersama file font tersebut.
